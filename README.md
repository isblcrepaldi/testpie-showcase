I use my son's nap time to build digital stuff for fun.

I am not a developer! I wanted to learn more about Git, system design, UX/UI standards, and CI/CD, so I jumped at the opportunity to use AI for practice.

What I'm working on: Testpie, a QA tool for writing test cases, running them against releases, and keeping an honest history of results. A saw a coworker's sad spreadsheet full of columns and dropdowns, and thought "hey! that's a cool little problem to solve!"

Built with
Next.js, React, TypeScript, Supabase (Postgres, Auth), Tailwind CSS, Radix UI, Vitest, GitHub Actions, and Vercel.
I built a small design system with tokens and components on top of Radix, plus CI checks that catch anyone drifting from it.
I also used AI to do market research, prioritization, token usage optimization planning, and skill.md assignments to different tasks across the building activity.

This repo is just an overview. It will be kept as a personal project for my own learning on how to ideate, research, build, and test with AI. 
I will add more documentation, images, thinking process, and learnings soon.
